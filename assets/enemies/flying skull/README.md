# Flying Skull

`dungeon_flying_skull.png` é a folha original preservada, 320×128, células de 32×32. Fileiras: idle/walk (10), ataque (6), hit (2), morte (7). Os frames são regiões do atlas em `resources/enemies/flying_skull/frames.tres`; nenhum PNG é regravado. O material preserva as cores originais laranja, creme e vinho, com flash somente ao receber dano.

Integração e medidas: `docs/BIOME_ENEMIES.md`.
