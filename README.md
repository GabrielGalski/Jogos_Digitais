# Jogos Digitais Concept

Protótipo acadêmico de um jogo de ação em primeira pessoa desenvolvido em Godot.

O projeto atual explora movimentação rápida, dash, efeitos de câmera e um sistema de três cartas equipáveis: Rifle, Shotgun e Katana.

## Projeto Godot

O projeto executável está na pasta `godot_fps`.

Para abrir, importe o arquivo `godot_fps/project.godot` no Godot 4.

## Controles atuais

- `W`, `A`, `S`, `D`: movimentação
- Mouse: controlar a câmera
- Scroll do mouse: trocar a carta selecionada
- Botão esquerdo: usar a carta selecionada
- Duplo toque em uma direção: dash
- Setas direcionais: inclinação da câmera
